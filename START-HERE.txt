BOOKIT SITE v67 — the homepage cast is now the approved concept ARTWORK
==============================================================================
This folder is the entire site. Changed since v65: public/vendor/care-motion.js,
public/vendor/care-core.local.js, and NEW folder public/assets/characters/
(seven small .webp cut-outs — make sure it uploads too).

What changed in v67
  • Every homepage character is now the actual approved concept art,
    cut out and mounted as an upright standee card in the 3D scene:
    the carer pushing the wheelchair along the hero path, the neighbour
    reading on the bench, the two friends chatting under the pergola,
    the gardener watering the beds, the mower worker, and the dog-walker
    in the stories scene. They mirror to match their direction of travel,
    bob gently as they walk, and the footprints / wheel tracks, rests,
    obstacle-aware routes and reduced-motion still frame all still work.
  • If a character image ever fails to load, that character quietly falls
    back to the v66 sculpted-3D version — the page never goes empty.
  • The six service-page dioramas still use the v66 sculpted-3D people
    (upgraded proportions, faces, uniforms). Swapping those to concept
    artwork as well is a straightforward follow-up if wanted.

Carried over from v66 (also in this folder)
  • The service-page diorama people were rebuilt in code to the concept
    style: realistic proportions, warm faces (brows, eyes, smile, blush),
    uniforms with lanyard and badge, knees that bend, hands that rest.
  • The homepage keeps that 3D cast too — but only as the automatic
    fallback behind the artwork standees.

Deploy: open github.com/thapasupreeya3-cpu/bookit-app/upload/main
and drag BOTH items from inside this folder (server.js and the
public folder) into the page. Commit, then: sudo bookit-update
(public/assets/characters/ is NEW — check those seven .webp files
appear in the repo after the upload.) Then hard-refresh the browser
(Cmd+Shift+R / Ctrl+F5) so the old animation module isn't cached.

Safe to delete from the repo whenever you like (nothing uses them):
