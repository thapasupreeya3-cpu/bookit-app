# v88.4.19 — Compact calendar popup

The calendar carer chooser now opens at a maximum width of 640px instead of
820px, with reduced spacing and a shorter header. Service and search remain
visible. Time, location and the remaining filters expand under Filters & visit
details, with the selected time and duration visible in its summary.

The carer card uses a smaller photo, a two-line biography preview, and an
expandable Carer details section containing all profile information. Previous,
Book and Next share one action row. Controls retain keyboard access and usable
touch targets. Invalid visit fields automatically reveal the details panel.

All recent-first ordering, local matching, filters, availability checks and
one-off/recurring booking behavior are preserved. No server or pricing changes.
This cumulative update-only ZIP applies over supplied v88.4.17 or the previous
v88.4.18 calendar update. It has not been deployed to the live website.
