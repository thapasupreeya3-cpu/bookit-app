HOW TO PUT THEM UP

Admin → Documents → "Blank forms — what a participant can download".
Each row: Choose File → pick the PDF whose name starts with that row's key →
Save. It appears on every participant's documents page immediately.

Eleven uploads, about five minutes.


TWO THINGS I HAD TO FIX TO MAKE THIS WORK

1. The request body cap. Any route not on an explicit allow-list is capped at
   100 KB, so the shelf refused every form over that size with a message about
   photos being shrunk. The form-templates route is now on the list, at 12 MB.
   That list is worth remembering: a new upload route added without being
   added here fails at whatever size the first real file happens to be.

2. LibreOffice writes /OpenAction into every PDF it exports — a "open at page
   one" destination, entirely inert, but the upload scanner refuses
   /OpenAction on sight because it CAN hold a Launch or JavaScript action.
   Rather than weaken the scanner to fit my own files, the PDFs are rebuilt
   page-by-page with qpdf so the catalogue has no OpenAction at all. The
   scanner is unchanged.

The shelf also takes Word files now, not just PDF — these are blanks an
administrator authored, and a .docx is often more useful to someone who will
type into it. They are still served as sandboxed attachments.
