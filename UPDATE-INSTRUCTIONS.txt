THE CARE WEB v88.4.6 — CURRENT UPDATE ONLY

REQUIRED BASE: v88.4.5
This ZIP contains only files changed since v88.4.5. It does not bundle earlier
payment, address, navigation, launch, overnight or booking-email updates.
Check your existing website at /api/version: APP_VERSION must be 88.4.5 before
applying this update. If it is older, install the already-supplied v88.4.5 first.

INSTALL ON YOUR EXISTING WEBSITE
1. Keep a backup of the existing source, database, uploads and protected settings.
2. Extract and MERGE this ZIP into your existing v88.4.5 repository, replacing
   matching files. Do not replace the repository with this partial ZIP.
3. Keep live database, uploads, photos, secrets and hosting settings in place.
4. Redeploy the updated source using your existing deployment process and Node
   22 (>=22.12 <23). This download has not been pushed to your remote repository;
   bookit-update alone cannot install it until your repository contains it.
5. Refresh the browser with Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows).
6. Confirm /api/version shows APP_VERSION 88.4.6 and SCHEMA_VERSION 88404.
   The added email-change history table is created automatically at startup.

WHERE TO FIND THE CHANGES
Participant: My profile > Your details > Email address > Change email.
Office: Admin > People > Verification > Participants > open the person >
Participant email address > Change email.
Invoice: Admin > Money > Invoices > Review query.

The old email remains active until the new inbox is confirmed. Existing issued
invoice payer details stay unchanged. A query response leaves payment paused
until the participant or authorised reviewer explicitly approves.
