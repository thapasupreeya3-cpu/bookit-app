It is an update package, not a standalone application.

1. Extract the ZIP. Upload the extracted files, not the ZIP itself.
2. Merge its files and folders into the existing repository root, containing
   server.js, package.json, public and lib. Replace matching files and retain
   other folder contents. Do not delete existing folders first.
   UPDATE-INSTRUCTIONS.txt is optional and is not application code.
3. Review and commit, then restart/redeploy through your usual process.
   Preserve the deployed database, uploads, photos, settings and configuration.
4. Refresh Admin > Verification. /api/version should report 88.2.5.
5. Select an HTML Service Agreement, Privacy consent and Medication consent.
   Check the preview and Open/Download actions. Also read a support plan.
6. Check a PDF: compact page/zoom controls, Fit and the three-dot menu for
   rotation and page text. Retry should appear only after an error. Check
   an image preview too. The package does not contain private runtime files.

Compare separately if your repository has newer edits not supplied here.

remain in place. See docs/CHANGELOG-v88.2.5.md and docs/TEST-RESULTS.md.

Confirm the previews on the deployed site after updating.
