THE CARE WEB - SETTINGS FIX v88.2.6

Supported earlier source versions: 88.2.5.
Use this package over v88.2.5, the HTML viewer and compact-controls update.

Contains 20 new or changed project files. Unchanged images, videos,
fonts, viewer assets and other source files are omitted.
This is an update package, not a standalone application.

1. Extract the ZIP. Upload the extracted files, not the ZIP itself.
2. Merge files and folders into the existing repository root, containing
   server.js, package.json, public and lib. Replace matching files and retain
   other folder contents. Do not delete existing folders first.
   UPDATE-INSTRUCTIONS.txt is optional and is not application code.
3. Review and commit, then restart/redeploy through your usual process.
   Preserve the deployed database, uploads, photos and configuration.
4. Refresh the site. /api/version should report 88.2.6.
5. Sign in as a worker and open Settings. The settings list and availability
   form should load. Also check Credentials, Earnings, Training, Jobs,
   Notifications, Accessibility, Security, Help and Profile.
6. A failed or stalled page now offers Try again instead of remaining on
   Loading indefinitely. Existing saved preferences and documents are retained.

Compare separately if your repository has newer edits not supplied here.
No schema change is needed from v88.2.5. The prior HTML/PDF preview fixes,
compact verification controls and automations are included in this release.
See docs/CHANGELOG-v88.2.6.md and docs/TEST-RESULTS.md.

Tests use the actual frontend renderer functions with real API responses from
an isolated server. Browser visual testing is blocked in this environment.
Confirm the worker Settings page on your deployed site after updating.

No existing files need to be deleted for this update.
