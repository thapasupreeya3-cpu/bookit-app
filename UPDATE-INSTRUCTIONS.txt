THE CARE WEB v88.4.7 — CURRENT UPDATE ONLY

REQUIRED BASE: v88.4.6
This ZIP contains only files changed since v88.4.6. Check /api/version on your
existing website: APP_VERSION must be 88.4.6 before applying this update.
If it is older, install the already-supplied updates through v88.4.6 first.

INSTALL ON YOUR EXISTING WEBSITE
1. Keep a backup of the existing source, database, uploads and protected settings.
2. Extract and MERGE this ZIP into your existing v88.4.6 repository, replacing
   matching files. Do not replace the repository with this partial ZIP.
3. Keep live database, uploads, photos, secrets and hosting settings in place.
4. Redeploy using your existing deployment process and Node 22 (>=22.12 <23).
   This download has not been pushed to your remote repository; bookit-update
   alone cannot install it until your repository contains these changed files.
5. Refresh with Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows).
6. Confirm /api/version shows APP_VERSION 88.4.7 and SCHEMA_VERSION 88404.
   This update introduces no new database tables or schema identifier.

WHERE TO FIND THE CHANGES
Participant: My profile > Your details > Home address.
Office: Next actions > choose the responsibility view > select a person tab.
Worker: Refer a friend or My earnings > your link and referral progress.
Office referrals: Admin > People > Worker referrals.

Old address links redirect to the profile section. Existing visit addresses
remain unchanged when the saved home address is edited.
Referral tracking begins when the friend successfully signs up with the code.
Completed ordinary shift hours count; sleepovers and meet-and-greets do not.
Referral eligibility does not itself pay the bonus.
