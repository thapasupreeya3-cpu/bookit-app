THE CARE WEB v88.4.18 — CALENDAR UPDATE ONLY

Apply this update over the v88.4.17 source from bookit-app-main (8).zip.
If you already applied the full v88.4.18 calendar ZIP, the feature code is the
same; these files can be merged safely into that source too.

1. Extract The-Care-Web-v88.4.18-calendar-update-only.zip.
2. Open the extracted folder. Drag ALL of its contents into the repository ROOT
   (the same level as server.js and package.json). Keep folder paths intact.
   Choose to replace matching files. This ZIP contains only changed files;
   keep all other repository files and merge folders rather than deleting them.
   For GitHub Upload files, open the repository root first, drag the extracted
   contents, then commit. Do not upload the ZIP itself or its enclosing folder.
3. Let the repository checks run, then deploy through your existing process.
   On the existing Lightsail setup, use sudo bookit-update after the commit.
4. Refresh the website. /api/version should report 88.4.18.

WHAT CHANGES
Bookings > Calendar: click a current or future date to browse your newest
connected carers first, followed by local carers, with all Find workers filters.
Choose a carer, then use Repeat this booking in the normal booking form.
Recurring support can be weekly or fortnightly, ongoing until cancelled or
ending on a chosen date. Ongoing has no total shift limit. Later requests are
added automatically; each needs worker acceptance.
Manage or cancel repeating bookings from the link below the calendar.

This source package does not deploy the live website. No new credentials or
hosting settings are required. Existing prices, billing rules, records and
uploads are preserved. Retain your usual backup before deploying.
