THE CARE WEB - SMALL UPDATE TO v88.2.4

Supported earlier source versions: 88.2.3.
Use this fix if you installed v88.2.3, the last worker-documents update.

This is an update package, not a complete application download.
It contains 67 new or changed project files. Unchanged images,
videos, fonts and other files are omitted.

1. Extract the ZIP on your computer. Do not upload the ZIP itself.
2. Open your existing GitHub repository root, containing server.js,
   package.json, public and lib.
3. Upload/merge the extracted files and folders at that root, preserving
   their paths and replacing matching files. Keep unchanged folder contents;
   do not delete existing folders first. UPDATE-INSTRUCTIONS.txt is optional.
4. Review and commit, then restart/redeploy through your usual process.
   Preserve the deployed database, uploaded documents, photos and settings.
   Source archives do not contain your workers' runtime files.
5. Refresh Admin > Verification. Open a worker > Worker documents.
   Select the uploaded PDF. Check page display, navigation, zoom and download.
   Include all new public/vendor/pdfjs resources and document-viewer assets.
   JPG/PNG images retain their direct preview.

No extra enclosing directory is needed. Compare separately if your repository
has later edits not supplied in this conversation. See STARTHERE.txt and
docs/CHANGELOG-v88.2.4.md for details and validation limits.

No schema migration is needed from v88.2.3; existing automations are retained.
The app cannot display worker copies held only outside its deployed file store.
The standalone HTML preview uses labelled examples, not live worker files.

No existing files need to be deleted for this update.
