THE CARE WEB - SMALL UPDATE TO v88.2.1

Use this package if your repository contains your uploaded bookit-app-main (4).zip (v88.1.4), or the supplied v88.1.5 or v88.2.0 release. It includes all subsequent fixes, workflow improvements and the v88.2.1 admin verification redesign.

This is an update package, not a complete application download.
It contains 78 new or changed project files. Unchanged files,
including existing images, videos and fonts, are omitted.

HOW TO UPLOAD
1. Extract this ZIP on your computer. Do not upload the ZIP itself.
2. Open the root of your existing GitHub repository: the folder containing
   server.js, package.json, public and lib.
3. Upload all extracted project files and folders into that root, preserving
   their paths and replacing matching files. Merge folders with the existing
   folders; keep their unchanged contents. Do not delete folders first.
4. Review and commit the changes. This instruction file is optional to upload.
5. Follow STARTHERE.txt and the release notes for installation or deployment.

Do not create a new enclosing folder or replace the repository with only this
package. The app still needs all unchanged files already in the repository.
