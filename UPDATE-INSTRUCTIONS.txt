THE CARE WEB v88.4.16 — CARE ROUTINE

This is a CURRENT UPDATE ONLY. Apply over v88.4.15.

1. Keep your existing source and routine database/upload backup.
2. Extract The-Care-Web-v88.4.16-care-routine-update-only.zip and merge its
   contents into the root of your existing repository, replacing matching files.
   This is not a complete replacement repository. No enclosing folder is needed.
3. Preserve your runtime database, uploaded documents/photos and hosting settings.
   Use the declared Node 22 runtime and your normal deployment process.
4. Redeploy your EXISTING website. No separate test website is required.
5. The startup migration adds booking_request_receipts for duplicate recovery.
   Existing bookings, pricing policies, invoices and documents remain in place.
   /api/version should report 88.4.16 and schema 88407. If your host explicitly
   sets SCHEMA_VERSION, update that override to 88407.
6. As a participant, open Bookings > Care routine > Add regular shift.
   Review weekly/fortnightly dates, prices, availability and skipped dates, then
   send only the real requests you intend the worker to receive. Requests need
   acceptance. Planning the next set requires a fresh review and does not renew
   automatically. Helpers need that participant's current booking permission.

This archive omits unchanged media, old update ZIPs and vendor files.
